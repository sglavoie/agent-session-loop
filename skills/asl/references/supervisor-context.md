## ASL Supervision

Supervising an `asl run` starts here. The `supervise` command below is the
loop: run it first, reissue it after every IDLE, and stop on DONE or LOST.
Run the route command for anything not listed - the detached helper launch,
`asl inbox resolve`, and which leaf `--help` to read - and load the full
skill only when the route is not enough.

- Route: `asl supervisor-guide` (add `--json` for the same model as data).
- Skill: codex `$asl asl run PLAN_DIR`; claude `/asl asl run PLAN_DIR`; copilot `/asl asl run PLAN_DIR`
- Reference: `asl/references/supervisor-context.md` under the skills directory.
- supervise: `asl outbox supervise PLAN_DIR --supervision-id SUPERVISION_ID`
- reply: `asl inbox reply PLAN_DIR --to QUESTION_ID --text REPLY_TEXT --wait-consumed --wait-timeout 300 --json`
- guidance: `asl inbox guidance PLAN_DIR --text GUIDANCE_TEXT --wait-delivered --json`
- status: `asl status PLAN_DIR --json`

## Full guide

`asl supervisor-guide` is authoritative; this copy exists so the skill
can answer without shelling out.

```text
ASL supervisor guide

Harness: undetected or ambiguous - every supported harness shown

Start supervision (Supervise one asl run end to end from a harness agent, passing the exact asl run command as the skill argument.)
  codex: $asl asl run PLAN_DIR
  claude: /asl asl run PLAN_DIR
  copilot: /asl asl run PLAN_DIR

Launch the helper directly
  helper: <skill-dir>/scripts/asl-autopilot.py
  supervision id: uuidgen
  launch: <skill-dir>/scripts/asl-autopilot.py --command 'asl run PLAN_DIR' --supervision-id SUPERVISION_ID --json --detach
  resume: printf '%s' 'REPLY_TEXT' | <skill-dir>/scripts/asl-autopilot.py --command 'asl run PLAN_DIR' --supervision-id NEW_SUPERVISION_ID --json --reply-stdin --detach
  handshake keys: ok, supervision_id, pid, plan_dir, result_path, stderr_path
  <skill-dir> is the installed asl skill directory, the one holding its SKILL.md. Mint one fresh supervision id per launch. The detached helper's verdict is the result.json at the handshake's result_path, never the launching turn's stdout.

Supervise and answer
  supervise: Long-poll the mailbox and print one of IDLE, ACTION questions=<n>, DONE outcome=<outcome> seq=<n>, LOST reason=<reason>. Reissue the identical command after IDLE; DONE and LOST both end the loop.
    asl outbox supervise PLAN_DIR --supervision-id SUPERVISION_ID
  reply: Answer an open worker question with a factual reply and confirm the worker consumed it.
    asl inbox reply PLAN_DIR --to QUESTION_ID --text REPLY_TEXT --wait-consumed --wait-timeout 300 --json
  resolve-continue: Close a plainly nonblocking question without supplying an answer; the worker resumes the same session.
    asl inbox resolve PLAN_DIR --to QUESTION_ID --action continue --wait-consumed --wait-timeout 300 --json
  resolve-pause: Turn a live wait into the ordinary terminal paused-run recovery path.
    asl inbox resolve PLAN_DIR --to QUESTION_ID --action pause --wait-consumed --wait-timeout 300 --json
  guidance: Steer implementation choices inside the selected session. Guidance is advice, not a guard: it cannot stop a run or change the session's scope or contract. The reply reports either 'delivered live' to the running turn or 'queued but not delivered', in which case it rides the next turn's prompt; only a guard enforces.
    asl inbox guidance PLAN_DIR --text GUIDANCE_TEXT --wait-delivered --json
  guard: Enforce, rather than advise. --deny-command blocks an action such as 'git push'; --protect-path freezes a file at its turn-start state and rejects the turn that changed it, retaining the change. Neither cancels the running turn -- only asl control abort does that.
    asl control guard add PLAN_DIR --deny-command 'CMD ARG ...' --protect-path ALIAS:PATH --reason TEXT --wait --json
  redirect: Urgent intervention: use only when the user has explicitly authorized this correction. Never self-authorize from a supervision signal, a failing check, or a suspicion that the worker is wrong. Unlike guidance, this interrupts the turn in flight: an accepted correction stops the worker and the runner continues the session on the predecessor's conversation. Submission is at-most-once -- a timeout reports the submission uncertain rather than retracting it, and resubmitting the same --operation-id with the same text is the same request, never a second one.
    asl control redirect PLAN_DIR --text REDIRECT_TEXT --session SESSION_ID --json
  redirect-status: Read what the redirect journal actually records: whether a correction was delivered, and whether the worker receipted it. The only way to settle an uncertain submission; watching is observational, so a timeout retracts nothing.
    asl control redirect-status PLAN_DIR --wait-acknowledged --json
  recover-conversation: Read why a run paused conversation-recovery-required and print the one-use relaunch that authorizes a fresh conversation. A read only: discarding an agent's saved reasoning is the user's decision, so run the printed asl run ... --fresh-conversation yourself only when the user says to. Supervision never resumes this pause on its own, and the autopilot helper refuses a command carrying --fresh-conversation outright.
    asl control recover-conversation PLAN_DIR --json
  acknowledge-external-changes: Preview a retained workspace incident. Acceptance requires explicit operator authorization of independent changes, a reviewed digest and reason; --checkpoint-retained separately authorizes retained-work commits. Never infer authorship or acknowledge a writable repository.
    asl acknowledge-external-changes PLAN_DIR --session SESSION_ID --repository ALIAS --json
  status: Recover run state after DONE outcome=error or LOST, and before treating a plan as idle.
    asl status PLAN_DIR --json
  read-result: Read the detached helper's verdict from the handshake's result_path once DONE ends the loop; fall back to asl status when the outcome was error.
    cat RESULT_PATH

Leaf help (these groups list leaves only; asl workbench is the exception and shows its serve flags on the parent)
  asl outbox supervise --help
  asl inbox reply --help
  asl inbox resolve --help
  asl inbox guidance --help
  asl control abort --help
  asl control redirect --help
  asl control redirect-status --help
  asl control recover-conversation --help
  asl bridge serve --help

Placeholders: PLAN_DIR, SUPERVISION_ID, QUESTION_ID, SESSION_ID, NEW_SUPERVISION_ID, REPLY_TEXT, GUIDANCE_TEXT, REDIRECT_TEXT, RESULT_PATH
```
